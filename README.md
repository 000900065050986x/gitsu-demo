# GitSU

Phone-ready workspace demo for **KiT the Branchfox**.

Live files:

- `GitSU.html` — shell + themes
- `gitsu.js` — client runtime
- `index.html` — jumps to `GitSU.html`

Open https://github.com/000900065050986x/gitsu-demo or raw `GitSU.html` in a browser.

This increment restores stacked tabs, KiT boot art, icon/theme pickers, edge chip, 3x3 tools, in-memory aurora-sync editor, local git/term/kit, and localStorage (`gitsu.v2`).

GitHub sign-in and MCP are still toggles only.
